1 · Potential outcomes

Potential outcomes

\[ \begin{array}{rcl} D_i \in \{0,1\} & \qquad & \text{treatment indicator} \\[2pt] Y_i(1) & & \text{potential outcome } \textbf{with} \text{ treatment} \\[2pt] Y_i(0) & & \text{potential outcome } \textbf{without} \text{ treatment} \\[2pt] \tau_i = Y_i(1) - Y_i(0) & & \text{individual causal effect} \end{array} \]

What we observe:

\[Y_i \;=\; D_i\,Y_i(1) + (1-D_i)\,Y_i(0) \;=\; \begin{cases} Y_i(1) & \text{if } D_i = 1 \\ Y_i(0) & \text{if } D_i = 0 \end{cases}\]

The fundamental problem of causal inference

We never observe both \(Y_i(1)\) and \(Y_i(0)\) for the same person: causality is a missing data problem.

Example: does smoking during pregnancy reduce birthweight?

Each vertical segment is one \(\tau_i\). We only ever see one end of it.

Two averages of \(\tau_i\): ATE and ATT

\[\text{ATE} = E[Y(1) - Y(0)] \qquad\qquad \text{ATT} = E[Y(1) - Y(0) \mid D = 1]\]

  • ATE: average effect over everyone. “What if all mothers smoked vs. none?”
  • ATT: average effect over the treated only. “How much lighter are smokers’ babies because their mothers smoked?”

What does the naive comparison of means estimate?

\[\underbrace{E[Y \mid D = 1] - E[Y \mid D = 0]}_{\text{naive comparison}} \;=\; \underbrace{E[Y(1) - Y(0) \mid D = 1]}_{\text{ATT}} \;+\; \underbrace{E[Y(0) \mid D = 1] - E[Y(0) \mid D = 0]}_{\text{selection bias}}\]

Age is a confounder: younger mothers smoke more and have lighter babies anyway ⇒ selection bias ≠ 0, so the naive comparison is neither the ATT nor the ATE.

2 · Randomization

Randomization kills selection bias

If \(D_i\) is assigned by a coin flip, it cannot depend on anything about the mother, observed or not:

\[\begin{aligned} \big(Y(1), Y(0)\big) \perp\!\!\!\perp D \;&\Longrightarrow\; \underbrace{E[Y(0) \mid D = 1] - E[Y(0) \mid D = 0]}_{\text{selection bias} \;=\; 0} \\[2pt] &\Longrightarrow\; E[Y \mid D = 1] - E[Y \mid D = 0] \;=\; \text{ATT} \;=\; \text{ATE} \end{aligned}\]

Caveat

Here randomization is not an option: assigning pregnant women to smoke would be unethical (and infeasible). For questions like this we need observational methods: matching, IV, RDD, DiD (the next TAs).

Hypothesis: IF we add an option “Wait & Save” THEN price-sensitive users who today take the bus or walk will now request a ride bringing more revenue.

Designing the experiment

  • Outcome \(Y_i\): revenue from user \(i\) in the 4 weeks of the test.
  • Treatment \(D_i = 1\) if user \(i\) sees app B (with “Wait & Save”), \(D_i = 0\) if app A (current menu).
  • Units: active users, each randomly assigned to A or B with probability ½ (a coin flip per user).

ATE = difference in means

Randomization ⇒ no selection bias ⇒ \(\;\text{ATE} = E[Y \mid D = 1] - E[Y \mid D = 0]\), estimated by \(\;\widehat{\text{ATE}} = \bar Y_1 - \bar Y_0\).

\[\begin{gathered} H_0:\ E[Y \mid D = 1] = E[Y \mid D = 0] \qquad\quad H_a:\ E[Y \mid D = 1] \neq E[Y \mid D = 0] \\[6pt] t = \frac{\bar Y_1 - \bar Y_0}{\sqrt{s_1^2/n_1 + s_0^2/n_0}} \;\overset{H_0}{\approx}\; N(0,1) \end{gathered}\]

Welch two-sample \(t\)-test (unequal variances): reject \(H_0\) at 5% if \(|t| > 1.96\).

y1 = app.loc[app.treat == 1, "revenue_post"]          # D = 1 (app B)
y0 = app.loc[app.treat == 0, "revenue_post"]          # D = 0 (app A)
print(f"mean(D=1) = {y1.mean():.2f}   mean(D=0) = {y0.mean():.2f}   difference = {y1.mean() - y0.mean():.2f}")
res = stats.ttest_ind(y1, y0, equal_var=False)          # Welch t-test
print(f"t = {res.statistic:.3f}   p-value = {res.pvalue:.4f}   df = {res.df:.1f}")

Heterogeneous treatment effects: by city

Joint test \(H_0: \theta_{BCN} = \theta_{PAR} = \theta_{LON} = 0\): \(F\) = 3.79, \(p\) = 0.010 → we reject that the effect is the same in every city. Revenue rises most in London (€10.18) and Paris (€6.18). In Madrid the estimate is negative: users mostly switch to the cheaper option instead of riding more, so revenue falls. Randomization holds within each city, so each city effect is causal (but pre-specify subgroups: slice the data 20 ways and one will look significant by chance).

Appendix

Take-up: offering ≠ using

We can offer “Wait & Save” (app B), but we cannot force users to choose it.

Users in B N Revenue before (€) Revenue during (€)
Did not choose it 1,239 40.71 45.25
Chose it 807 81.04 84.89
  • Only 39% of B users chose the new option.
  • \(\hat\beta_1\) = €3.10 is the effect of being offered the option: the intention-to-treat (ITT). Still causal, and the relevant number for the launch decision.
  • ❌ Don’t compare choosers vs non-choosers: choosers already spent much more before the test → self-selection, the same problem as smokers.
  • Effect on those who actually chose it ≈ ITT / take-up = 3.10 / 0.39 = €7.85 (more on this with IV, TA8).

When SUTVA fails, change the unit of randomization

SUTVA: my outcome depends only on my own treatment, not on other users’ treatment.

How the spillover happens. Users in the same city share the same pool of drivers. B users request extra (cheap) rides → fewer free drivers → A users wait longer, see surge prices, or give up → A’s revenue falls because of B. So \(\bar Y_0\) no longer estimates \(E[Y(0)]\), and \(\bar Y_1 - \bar Y_0\) overstates the effect of launching the option for everyone.

Fix: randomize at the level where the interaction happens: the city (the driver market). All users in a city see the same app, so spillovers stay within one arm; cluster SEs by city. Cost: few units (cities) → much less power. In practice firms use many cities, or switchback designs (randomize city × time slot).
