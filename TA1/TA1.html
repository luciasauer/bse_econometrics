Matrix Operations using R

# Define matrix A and vector b
A <- matrix(c(2, 3, 10,
              4, 1, 12,
              7, 2, 1),
            nrow = 3, byrow = TRUE)

b <- c(5, 6, 10)

# Inverse A
A_inverse <- solve(A)
x <- A_inverse %*% b

# Solve Ax = b
x <- solve(A, b)
print(x)

Derivatives of a vector

Gradient with respect to a vector

  • In single-variable calculus:

    \(\frac{d}{dx} f(x)\) is the slope of a scalar function of one variable.

  • In multivariable calculus:

    If \(f(z_1, z_2)\), we can group the variables into a vector:

    \[ z = \begin{bmatrix} z_1 \\ z_2 \end{bmatrix} \]

    then the derivative with respect to a vector is the gradient:

    \[ \nabla_z f(z) = \begin{bmatrix} \frac{\partial f}{\partial z_1} \\[6pt] \frac{\partial f}{\partial z_2} \end{bmatrix} \]

👉 Take the partial derivative with respect to each coordinate, then stack them in a column vector.

Consider: \[ a = \begin{bmatrix} a_1 \\ a_2 \end{bmatrix} \quad z = \begin{bmatrix} z_1 \\ z_2 \end{bmatrix} \quad B = \begin{bmatrix} b_{11} & b_{12} \\ b_{21} & b_{22} \end{bmatrix} \]

Exercises

Verify, by showing all the relevant steps, that:

\[ \begin{aligned} (i) & \quad \frac{\partial z'a}{\partial a} = z \\[6pt] (ii) & \quad \frac{\partial a'z}{\partial z} = a \\[6pt] (iii)& \quad \frac{\partial z'B z}{\partial z} = 2Bz \quad \text{since B is symmetric} \end{aligned} \]

Histograms & Kernel Density Estimation

Density Estimation - Introduction

Given some observations from some variable \(X\), we would like to obtain an estimate of its density.

Parametric vs Nonparametric

  • Parametric: choose a density family (normal, exponential, uniform…) and estimate its parameters from data.

Problem: what if \(X\) doesn’t follow that family?

  • Nonparametric (histograms, KDE) estimates the distribution without strong assumptions.

Histogram

Key idea: A histogram is a graphical tool to visualize the distribution of a dataset.

  • A nonparametric method to estimate the probability density function (PDF)
  • Groups data into intervals (bins)
  • Plots the frequency of data points in each bin

Concept of Density

Let’s differentiate between frequency histograms and density histograms, using a dataset with 12 observations: [2, 3, 5, 5, 6, 8, 8, 8, 10, 12, 15, 17]

123Binwidth

If we fix the number of bins ex-ante, we must derive the binwidth:

\[ n_{bins} = 3 \;\Longrightarrow\; \text{binwidth} = h = \frac{\max(x) - \min(x)}{n_{bins}} = \frac{17 - 2}{3} = 5 \]

Mathematically, for bin width \(h\) and number of observations \(n\):

\[ \hat{f(x)} = \frac{1}{nh} \sum_{i=1}^n \mathbf{1}\{x_i \in \text{bin}(x)\} \]

Density ≠ Probability

Exam question

Could the range of values of the vertical axis in a histogram be greater than 1? Justify your answer.

Imagine the following data, narrower range (0.10 to 0.35):

[0.10, 0.15, 0.15, 0.20, 0.20, 0.20, 0.25, 0.30, 0.30, 0.35]

We set 5 bins (\(h = 0.25/5 = 0.05\)), usual estimator:

\[\hat f(x) = \frac{1}{nh}\sum_{i=1}^n \mathbf{1}\{x_i \in \text{bin}(x)\}, \; nh = 0.5\]

Kernel Density Estimation

Key idea: Smooth, nonparametric estimate of the probability density function

  • Instead of counting frequencies in bins, KDE places a smooth kernel function (usually Gaussian) centered at each data point, and then averages them.

The limitation KDE fixes

A histogram is discrete: it jumps abruptly at every bin edge. KDE is continuous by construction — no bins, no edges, just a smooth curve.

The Kernel Function

\[\hat{f}_h(x) = \frac{1}{nh} \sum_{i=1}^n K\left(\frac{x - x_i}{h}\right)\]

  • \(n\) is the number of observations
  • \(h\) is the bandwidth (controls how much each observation’s influence spreads)
  • \(K\) is the kernel — any symmetric function integrating to 1. Gaussian is the most common choice, but not the only one:

Coding Example in Python

  • Code
  • Output
import seaborn as sns
x = sns.load_dataset('tips')['total_bill']
for bw in [0.3, 2, 10]:
    sns.kdeplot(x, bw_adjust=bw, label=f"Bandwidth = {bw}")
  • Small \(h\): very wiggly estimate (low bias, high variance).
  • Large \(h\): oversmoothed estimate (high bias, low variance).
  • Same bias-variance trade-off as the binwidth \(h\) in a histogram — just for a smooth curve instead of bars.

Coding example in R

library(ggplot2)
library(readr)

tips <- read_csv("https://raw.githubusercontent.com/mwaskom/seaborn-data/master/tips.csv")
x <- tips$total_bill

for (bw in c(0.3, 1, 2)) {
  print(ggplot(data.frame(x = x), aes(x = x)) +
          geom_density(adjust = bw, color = "blue") +
          ggtitle(paste("Bandwidth =", bw)))
}

Quick LaTeX Guide

What is LaTeX (and why use it)?

LaTeX is a typesetting system, not a word processor: you write plain-text markup, and it compiles into a professional PDF — like code, but for documents.

Why for assignments

  • Clean, consistent math notation
  • Regression tables & figures exported directly from Python/Stata — no manual formatting
  • The same source always reproduces the same PDF

Key Commands: Structuring a Document

\section{Introduction}
This is the introduction to the assignment.

\subsection{Motivation}
Here we explain why this analysis matters.

\subsection{Data}
We describe the dataset used.

\section{Results}
We now present our findings.
  • \section{} numbers top-level headings; \subsection{} nests one level in
  • Numbering, spacing, and the table of contents update automatically
  • No manual “1.2” typing, no forgetting to renumber after edits

Key Commands: Math Notation

\begin{equation}
y_i = \beta_0 + \beta_1 x_i + \varepsilon_i
\end{equation}

\[

  • equation numbers the line; \[...\] (or $...$) doesn’t
  • rows separated by \\, entries by &

import statsmodels.formula.api as smf
from stargazer.stargazer import Stargazer

m1 = smf.ols("tip ~ total_bill", tips).fit()
m2 = smf.ols("tip ~ total_bill + size", tips).fit()

sg = Stargazer([m1, m2])
sg.rename_covariates({"total_bill": "Total Bill", "size": "Party Size"})

with open("regression.tex", "w") as f:
    f.write(sg.render_latex())
