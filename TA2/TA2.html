From averages to regression

Conditional Mean

Conditional Mean

Population concept: The conditional mean of \(Y\) given \(X=x\) is the expected value of \(Y\) in the sub-population where \(X=x\):

\[E[Y|X=x]\]

Sample estimate: The sample conditional mean is the average of all observed \(Y_i\) for which \(X_i = x\): \[ \hat{E}[Y|X=x] = \frac{1}{N_x} \sum_{i: X_i = x} Y_i \] where \(N_x\) is the number of observations with \(X_i = x\).

👉 The OLS estimator aims to model the conditional mean function, i.e., \(E[Y|X]\), as a function of \(X\).

From averages to a fitted model

OLS in Matrix Algebra

Using our dataset, we can write the model for a representative observation \(i\): \[price_i = \beta_1 + \beta_2 \cdot bdrms_i + \beta_3 \cdot sqrft_i + \beta_4 \cdot colonial_i + \varepsilon_i \]

We can express this model for a set of \(n\) representative observations in matrix form as:

\[{y} = {X} {\beta} + \varepsilon\]

where: \[ \small \begin{bmatrix} price_1 \\ price_2 \\ \vdots \\ price_n \end{bmatrix}, \quad \begin{bmatrix} 1 & bdrms_1 & sqrft_1 & col_1 \\ 1 & bdrms_2 & sqrft_2 & col_2 \\ \vdots & \vdots & \vdots \\ 1 & bdrms_n & sqrft_n & col_n \end{bmatrix}, \quad \begin{bmatrix} \beta_1 \\ \beta_2 \\ \beta_3 \\ \beta_4 \end{bmatrix}, \quad \begin{bmatrix} \varepsilon_1 \\ \varepsilon_2 \\ \vdots \\ \varepsilon_n \end{bmatrix} \]

1. Estimate the OLS Coefficients

Starting from the OLS objective function: \[ \min_{{\tilde{\beta}}} SSE(\tilde\beta) = \min_{{\tilde{\beta}}} \sum_{i=1}^n (y_i - x_i'\tilde\beta)^2 = \min_{{\tilde{\beta}}} ({y} - {X}{\tilde{\beta}})'({y} - {X}{\tilde{\beta}}) \]

Taking FOC and solving gives \(\hat\beta\):

\[\hat{\beta} = \left(\sum_{i=1}^{n} x_i x_i'\right)^{-1} \sum_{i=1}^{n} x_i y_i\]

Or equivalently, in matrix form:

\[\hat{\beta} = \; ({X}'{X})^{-1}{X}'{y}\]

Compute OLS coefficients in Python

import numpy as np

df["intercept"] = 1
X = df[["intercept", "bdrms", "sqrft", "colonial"]].to_numpy()
y = df["price"].to_numpy()
n = X.shape[0]

# matrix form: X'X and X'y
X_tX = X.T @ X
X_ty = X.T @ y
beta_hat = np.linalg.solve(X_tX, X_ty)

print(np.round(beta_hat, 2))
[-21.55  12.49   0.13  13.08]

Fitted model:

\[ \small \hat{price}_i = -21.55 + 12.49\cdot bdrms_i + 0.13\cdot sqrft_i + 13.08\cdot colonial_i \]

where the dependent variable price is in $1000s.

2. Compute the fitted values and OLS residuals

\[{\hat{y}} = {X}\hat{\beta}\]

# Fitted values
y_hat = X @ beta_hat

\[ \hat{\varepsilon} = {y} - {\hat{y}} \]

# Residuals
epsilon_hat = y - y_hat

Units

  1. In what units are the fitted values \({\hat{y}}\)?
  2. In what units are the residuals \({\hat{\varepsilon}}\)?

3. Calculate the Sum of Squared Errors (SSE)

\[SSE = {\hat{\varepsilon}}'{\hat{\varepsilon}}\]

Note that this is exactly the same as:

\[ SSE = \sum_{i=1}^{n} (\hat{\varepsilon}_{i})^{2} = \sum_{i=1}^n (y_i - \hat{y}_i)^2\]

# Sum of Squared Errors
SSE = epsilon_hat.T @ epsilon_hat
round(SSE, 2)
np.float64(334982.95)

SSE Units

Note: The SSE is in the squared units of the dependent variable (here, the price in 1000s of dollars).

4. Compute the \(R^2\) statistic

\[R^2 = 1 - \frac{SSE}{SST}\]

where \[SST = ({y} - \bar{y}{1})'({y} - \bar{y}{1})\]

# Total Sum of Squares
y_bar = y.mean()
SST = (y - y_bar).T @ (y - y_bar)
r2 = 1 - SSE / SST
round(r2, 4)
np.float64(0.635)

\(R^2\) interpretation

Note: The \(R^2\) is unit free. It tells us that about 64% of the sample variation in house price is explained by the model.

3. Python Preset Functions

Preset Functions

All the operations we did in matrix algebra can be done using preset functions in Python.

  • Python: statsmodels library, specifically the OLS class from statsmodels.api.

Code example in Python

import statsmodels.api as sm
from statsmodels.formula.api import ols

# Estimate the model with the ols formula API
model = ols("price ~ bdrms + sqrft + colonial", data=df).fit()
beta_hat = model.params
y_hat = model.fittedvalues
epsilon_hat = model.resid

sse = (epsilon_hat**2).sum()
r2 = model.rsquared
print("Coefficients (betas):\n", beta_hat)

print("\nSSE:", round(sse, 2))
print("R^2:", round(r2, 4))

5. Numerical Properties of OLS

Numerical Property of OLS

These properties are independent of the statistical assumptions, they are purely mathematical properties of the OLS estimator, that hold given a sample.

  1. \[\sum_{i=1}^{n} \hat{\varepsilon_i} = 0\]

  2. OLS is unit-dependent, hence SSE is also unit-dependent.
