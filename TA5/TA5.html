Monte Carlo Experiments: Consistency

From TA3 to consistency

In TA3 we fixed \(n\) and looked at the sampling distribution of an estimator across many samples. Now we let \(n\) grow.

Consistency

An estimator \(\hat\theta_n\) is consistent for \(\theta\) if it converges in probability to \(\theta\):

\[\text{plim}_{n \to \infty}\; \hat\theta_n = \theta\]

The picture we want to see: as \(n\) grows, the sampling distribution of \(\hat\theta_n\) collapses onto the true value \(\theta\).

The Monte Carlo recipe is the same as in TA3, repeated for several sample sizes.

Consistency of the sample mean: your dgp

rng = np.random.default_rng(0)

def simulate_means(n, R=1000, mu=0, sigma=1):
    """Generate R samples of size n de from a Normal(mu, sigma) and return R means"""
    means = np.zeros(R)
    for r in range(R):
        sample = rng.normal(loc=mu, scale=sigma, size=n)   # a sample of size n
        means[r] = sample.mean()                           # store the mean
    return means

# example: z ~ Normal(2, 1)
mu, sigma = 2, 1
ns = [10, 100, 1_000, 10_000]
means = {n: simulate_means(n, mu=mu, sigma=sigma) for n in ns}

Consistency of OLS: a dgp with four regressors

\[y_i = 1 + 2\,x_{i2} - 1\,x_{i3} + 0.5\,x_{i4} + \varepsilon_i\]

\[x_{i2} \sim N(0,1), \qquad x_{i3} = 0.5\,x_{i2} + u_i,\;\; u_i \sim N(0,1), \qquad x_{i4} \sim \text{Bernoulli}(0.3)\]

\[\varepsilon_i = \frac{\chi^2_i(3) - 3}{\sqrt 6}\;\; \text{(independent of } X\text{)}\]

  • \(x_2\) and \(x_3\) are correlated; \(x_4\) is a dummy
  • The error is not normal (skewed), but it has mean 0 and is independent of the regressors

Recall from lecture

OLS is consistent if the observations are i.i.d., \(E(x_i\varepsilon_i) = 0\), and \(\text{plim}\,\frac{X'X}{n}\) exists and is finite and non-singular. Normality is not needed.

Monte Carlo in code

BETA = np.array([1, 2, -1, 0.5])

def simulate_ols(n, R=1000, seed=0):
    rng = np.random.default_rng(seed)
    betas = np.empty((R, 4))
    for r in range(R):
        x2 = rng.normal(0, 1, n)
        x3 = 0.5 * x2 + rng.normal(0, 1, n)
        x4 = rng.binomial(1, 0.3, n)
        eps = (rng.chisquare(3, n) - 3) / np.sqrt(6)
        X = np.column_stack([np.ones(n), x2, x3, x4])
        y = X @ BETA + eps
        betas[r] = np.linalg.solve(X.T @ X, X.T @ y)
    return betas

ns_ols = [50, 200, 1_000, 5_000]
betas_by_n = {n: simulate_ols(n) for n in ns_ols}

OLS estimates collapse onto the true \(\beta\)’s

For every estimated coeff., the KDE gets narrower and taller around the true value as \(n\) grows, even though \(\varepsilon\) is not normal.

Non-spherical disturbances

Spherical disturbances

The spherical disturbances assumption includes two assumptions on the behaviour of the disturbances:

  1. Homoskedasticity: \(\;var(\varepsilon_i \mid X) = \sigma^2\)
  2. Uncorrelatedness: \(\;cov(\varepsilon_i, \varepsilon_j \mid X) = 0, \;\; \forall i \neq j\)

\[Var(\varepsilon \mid X) = \sigma^2 I_n\]

Now we consider the possibility of abandoning one of these assumptions, and see how estimation and inference change.

1. Heteroskedasticity

Let’s start by relaxing the homoskedasticity assumption:

\[var(\varepsilon_i \mid X) = \sigma^2_i\]

The variance-covariance matrix of the disturbances is now:

\[\Sigma = \begin{bmatrix} \sigma_1^2 & 0 & 0 & \cdots & 0 \\ 0 & \sigma_2^2 & 0 & \cdots & 0 \\ 0 & 0 & \sigma_3^2 & \cdots & 0 \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & 0 & \cdots & \sigma_n^2 \end{bmatrix} \]

House prices data

The hprice3 dataset (Wooldridge) contains 321 house sales. We estimate:

\[ price_i = \beta_1 + \beta_2\, area_i + \beta_3\, rooms_i + \varepsilon_i \]

2. Testing for heteroskedasticity

Breusch-Pagan steps

  1. Estimate the original model and obtain the residuals \(\hat\varepsilon_i\)
  2. Run the auxiliary regression: \[\hat{\varepsilon}_i^{2} = \alpha_1 + \alpha_2\, area_i + \alpha_3\, rooms_i + v_i\]
  3. Test \(\;H_0: \alpha_2 = \alpha_3 = 0\) (homoskedasticity) \(\;\) vs. \(\;H_1:\) at least one \(\alpha_j \neq 0\) (heteroskedasticity)

Finite sample version \[ F = \frac{(\widetilde{RSSE} - \widetilde{SSE})/2}{\widetilde{SSE}/(321-3)}\underset{H_0}{\sim} F_{2,\, 321-3} \]

Asymptotic version \[ n \widetilde{R}^2 \underset{H_0}{\overset{a}{\sim}} \chi^2(2) \]

Breusch-Pagan test in Python

Robust SE

Under heteroskedasticity, \(\hat\beta\) is still unbiased, but \(\hat\sigma^2(X'X)^{-1}\) is no longer its variance. The robust (White, HC1) estimator is:

\[\widehat{Var}_{HC1}(\hat\beta) = \frac{n}{n-K}\,(X'X)^{-1}\Big(\sum_{i=1}^n \hat\varepsilon_i^2\, x_i x_i'\Big)(X'X)^{-1}\]

model_robust = smf.ols("price ~ area + rooms", data=df).fit(cov_type="HC1")
print(model_robust.summary(slim=True).tables[1])

Bootstrapped Standard Errors

The bootstrap idea

The robust SE needs a formula. For many estimators the formula is hard (or impossible) to derive. The bootstrap estimates the standard error by resampling the data we have.


Remember the Monte Carlo experiment from TA3: draw many samples from the population, compute the estimator in each, look at the spread.

The problem: with real data we do not know the population.

The bootstrap trick

Treat the observed sample as if it were the population: draw many samples of size \(n\) with replacement from it, compute the estimator in each, and use the sd of those estimates as the standard error.

Paired bootstrap SE for OLS

The same recipe works for \(\hat\beta\): resample rows \((y_i, x_i)\) with replacement, keeping each \(y_i\) together with its \(x_i\) (the paired bootstrap).

B = 500
rng = np.random.default_rng(123)

boot = []
for b in range(B):
    df_b = df.sample(n=len(df), replace=True, random_state=rng)
    fit_b = smf.ols("price ~ area + rooms", data=df_b).fit()
    boot.append(fit_b.params)

boot = pd.DataFrame(boot)
boot_se = boot.std()

Bootstrap regression table

With the bootstrap SE we build the usual table, using normal-based inference:

from scipy import stats

table = pd.DataFrame({"coef": model.params, "boot se": boot_se})
table["z"] = table["coef"] / table["boot se"]
table["P>|z|"] = 2 * (1 - stats.norm.cdf(table["z"].abs()))
table["[0.025"] = table["coef"] - 1.96 * table["boot se"]
table["0.975]"] = table["coef"] + 1.96 * table["boot se"]
table.round(4)
